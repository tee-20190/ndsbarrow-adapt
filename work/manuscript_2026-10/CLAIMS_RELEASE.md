(`DRAFT_v10.md`). One row per claim tag [Cnnn] cited in `DRAFT_v10.md` (225 IDs). Ledger rows not cited in v10 are

sentence it drops is the target-venue line (C226), whose row is kept here.
Paths are relative to the author's working repository; files that are not in this release are listed in
`WITHHELD.md` or are outside the release scope. Line numbers refer to the working tree at the ledger revision named in
the row (v0/v1 2026-10-09 ~02:10Z; v4, v5 and v7 later the same day; v10 on 2026-10-10). JSON values are cited by line
where a unique line exists, otherwise by JSON path plus line range. Short hexadecimal IDs (e.g. `1ea377ca`) are git
commits of the project repository; truncated hexadecimal values with an ellipsis are SHA-256 file hashes.

Provenance: this ledger was compiled and checked by AI-assisted sessions working under the author's direction (see
the paper's AI statement). "This session" in a row means the AI-assisted session that made that row's revision
(v0, v1, v4, v5, v7 or v10). Edits made for public release (removed internal names, local paths and identifiers) are
listed in `CLAIMS_RELEASE_SCRUB_LOG.md`; no claim, value, status, commit hash or non-private receipt path was changed.
